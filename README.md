# CS50x – Introduction to Computer Science

This repository contains my code, practice problems, and programming exercises completed while learning through [CS50x – Introduction to Computer Science](https://cs50.harvard.edu/x/), offered by Harvard University.

## About the Course

CS50x introduces fundamental concepts of computer science and programming, covering problem-solving, algorithms, data structures, and software development using different programming languages.

## Topics Covered

- C Programming
- Arrays and Algorithms
- Memory and Pointers
- Data Structures
- Python Programming
- SQL and Databases
- HTML, CSS, and JavaScript
- Flask and Web Development
